# PIC16F877A-Interfacing-Projects

🧠 Aim of the Repository

To understand and implement basic peripheral interfacing using PIC16F877A microcontroller through simple and progressive embedded C programs.

🔧 Hardware Requirements

PIC16F877A Microcontroller

20 MHz Crystal Oscillator

Power Supply (5V)

Breadboard / PCB

LEDs, Resistors

Relay Module

7-Segment Display

16×2 LCD

4×3 Matrix Keypad

Push Buttons

💻 Software Requirements

MPLAB X IDE

XC8 Compiler

Proteus (for simulation)

📂 List of Experiments
Experiment 1

Title: Single LED Interface using PIC16F877A
Aim: To interface and control a single LED using PIC16F877A.
Concepts Used: GPIO, TRIS Register
Output: LED turns ON and OFF

Experiment 2

Title: 8 LED Interface using PIC16F877A
Aim: To control multiple LEDs using a single port.
Concepts Used: PORT manipulation, Bitwise operations
Output: LED pattern display

Experiment 3

Title: Relay Interface using PIC16F877A
Aim: To control a relay using PIC16F877A.
Concepts Used: Digital Output, Driver Circuit
Output: Load switching through relay

Experiment 4

Title: External Interrupt Interface using PIC16F877A
Aim: To demonstrate external interrupt operation.
Concepts Used: INT interrupt, ISR
Output: Event-based LED control

Experiment 5

Title: Timer Interrupt Interface using PIC16F877A
Aim: To generate time-based interrupts using timer.
Concepts Used: Timer0 / Timer1, Prescaler
Output: Periodic task execution

Experiment 6

Title: 7-Segment Display Interface using PIC16F877A
Aim: To display digits using a 7-segment display.
Concepts Used: Lookup table, GPIO
Output: Digits 0–9 displayed

Experiment 7

Title: Multiplexed 2-Digit 7-Segment Display
Aim: To display two digits using multiplexing technique.
Concepts Used: Multiplexing, Timing control
Output: Two-digit number display

Experiment 8

Title: 4×3 Matrix Keypad Interface using PIC16F877A
Aim: To read keypad input using row-column scanning.
Concepts Used: GPIO Input, Matrix scanning
Output: Key value detection

Experiment 9

Title: 16×2 LCD Interface using PIC16F877A (8-bit Mode)
Aim: To interface LCD in 8-bit mode.
Concepts Used: LCD commands, Data bus
Output: Text displayed on LCD

Experiment 10

Title: 16×2 LCD Interface using PIC16F877A (4-bit Mode)
Aim: To interface LCD using 4-bit mode to save pins.
Concepts Used: Nibble transfer, LCD timing
Output: Efficient LCD display

📝 Conclusion

All basic interfacing experiments using PIC16F877A were successfully implemented and tested. These experiments help in understanding microcontroller architecture, peripheral control, and embedded C programming.
